# GitHub 每周情报看板 · 使用说明

## 这是什么

一个**单文件网页**（`dist/index.html`），每周一自动更新。8 个标签：

| 标签 | 内容 |
|---|---|
| 🔥 本周黑马 | 全 GitHub 这周 star 涨得最猛的 |
| 🏆 巨头榜 | 全 GitHub 总 star TOP30 |
| 💼 工作提效/生活创意 | 办公工具 · 生活效率 · 个人理财 · 笔记 · 家庭教育 · 图片创作 · 音乐音频 · 财务记账 |
| 🏭 行业提效 | HR · 销售 · 物流 · 医疗 |
| 🎓 AI 学习 | 非 IT 背景 / IT相关背景 |
| 🚀 AI 应用 | AI 框架 + Agent 装备（MCP 服务器等） |
| 💻 AI 编程 | AI 编程助手 |
| 🧠 大模型 | 开源大模型 / 推理引擎 |

每个榜单可切换「总 star 榜 / 增速榜」。点任意一行直达 GitHub 项目页。

## 怎么看

- **电脑**：浏览器打开 `dist/index.html`，或访问部署后的网址
- **手机/微信**：把 `dist/index.html` 文件直接发到微信，点开就能看（文件自带数据，不需要联网）
- **搜索**：顶部搜索框，支持口语词（搜"AI"="人工智能"="大模型"）
- **加自己关注的仓库**：页面底部"高级"，只存在自己浏览器里

## 每周怎么更新（全自动）

GitHub Actions 每周一 09:00（北京时间）自动：抓数据 → 自动翻译新项目 → 生成网页 → 发布。**你的电脑开不开机都不影响。**

手动更新一次：
```bash
python3 scripts/fetch.py       # 抓数据（约 10 分钟，限速防封）
python3 scripts/translate.py   # 翻译新项目（增量，约几分钱）
python3 scripts/render.py      # 生成网页
```

## 想改领域/加仓库

改 `data/categories.json`：
- `repos` 加一行 `"作者/仓库名"` 加入该领域
- `search_queries` 是该领域的自动补位规则（GitHub 搜索语法，单条件）
- 每个分类自动补足到 20 个以上，不足会放宽条件再补
- 改完跑上面三条命令生效

## 看懂榜单的规则

- **增速**：与上周相比。第一周运行大部分项目标"新收录"，下周起全量有增速
- **僵尸项目**：超过一年没更新的标灰 +"久未更新"
- **上线 N 周**：半年内的新项目会标注周龄
- **License 标签**：MIT/Apache 可自由商用；GPL/AGPL 商用有限制
- **黑马提醒**：涨得快 ≠ 好，可能是炒作
- **边界**：只收录开源软件，Obsidian/Notion 等闭源软件不在榜内

## 文件结构

```
github-board/
├── data/
│   ├── categories.json      # 领域和仓库清单（要改就改它）
│   ├── plain_names.json     # 手写人话解释
│   ├── translate_cache.json # 自动翻译缓存（只增不删）
│   └── latest.json          # 最新数据（脚本生成）
├── history/                 # 每周快照（只增不删，算增速用）
├── scripts/
│   ├── fetch.py             # 抓数据
│   ├── translate.py         # 自动翻译（DeepSeek）
│   └── render.py            # 生成网页
└── dist/
    └── index.html           # 看板本体（唯一产物）
```
